# Educated Voter AL

**Educated Voter AL** is a mobile-first Progressive Web App for Alabama voter information and voter assistance, powered by Educated Voters PAC.

## Current MVP
- Direct link to Alabama's official voter-registration and polling-place lookup
- Absentee voting information
- 2026 General Election deadlines
- Selector for all 67 Alabama counties
- Montgomery County pilot information
- Photo voter-ID information
- Official 2026 election/sample-ballot resources
- Voting-help phone links
- Private on-device Vote Plan checklist
- PWA install support
- Ride-to-the-polls module placeholder

## Privacy
The app does not collect voter-registration credentials. Registration and polling-place lookups happen on Alabama's official voter-information system. The Vote Plan checklist is stored only in the user's local browser.

## Official source backbone
- Alabama Votes: https://www.sos.alabama.gov/alabama-votes
- My Voting Information: https://myinfo.alabamavotes.gov/voterview
- 2026 Election Information: https://www.sos.alabama.gov/alabama-votes/voter/election-information/2026
- Absentee Voting: https://www.sos.alabama.gov/alabama-votes/voter/absentee-voting
- County Official Lookup: https://www.sos.alabama.gov/city-county-lookup
- Montgomery County Election Center: https://www.montgomeryvotesal.gov/
